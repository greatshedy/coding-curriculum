How each lesson works

🎯

Read the concept

Short, plain-English explanation of the idea for the week, plus a key teaching point.

📖

Lesson notes

A reading note for students — the big idea, words to know, key takeaways and discussion questions — plus a full teacher briefing. Printable.

▶️

Run it live

Press Run and watch the idea happen — move it, break it, change the numbers and run it again.

🧱

Build it yourself

Follow the block recipe or code template and the step-by-step activity to make it your own.
