JavaScript: Web Development

Instructor guides, student handouts, runnable code templates and assessments — everything you need to teach modern JavaScript, from the first console.log() through the DOM, events and fetch() to a finished, published web app.

Key philosophy

Read it, run it, change it. Every week ships a runnable code template, so students see the result in the browser immediately.

Target students
JSS 3, SS 1 and SS 2. No prior JavaScript needed.
Starting point
Students already know some HTML and CSS. This course adds JavaScript.
End goal
Every student builds and publishes a working interactive web app.
Two tracks
Track A has laptops. Track B works on paper with written assessments.

How each lesson works

Every week page is the full classroom package, split into four tabs.

📄

Two tracks, one course

Track A

With system

Students have laptops. They code along, run the templates in the browser, and are assessed with peer pair-check checklists.

  • ✓ Run and edit every code template
  • ✓ Peer pair-check after each lesson
  • ✓ Build a real mini-project in Term 3
Track B

No system

No laptops required. Students work through the printed handouts and are assessed with written quizzes and design documents.

  • ✓ Printed student handouts
  • ✓ Written quiz with code-trace questions
  • ✓ Paper design document and rubric
Term 3: modern JavaScript & real-world apps

Every student plans and builds one mini-project — a to-do list, a calculator or a form validator — then presents it on showcase day.

Terms at a glance

Click any week to open the instructor guide, handout, code template and assessment.

Assessment at a glance

Weekly (Track A)

Peer pair-check checklist, every week:

  • Does the code run without errors?
  • Can the author explain the code in their own words?
  • Can a partner point to a specific concept in the code?

Weekly (Track B)

Written quiz, every week:

  • Short-answer questions on the concept
  • Code-trace questions ("what will print?")
  • Write-a-line questions
  • Answer key hidden behind a collapsible

Final (Term 3)

  • Weekly: recap quiz (6 questions)
  • Project: project design document + presentation
  • Both: project showcase rubric
