JavaScript: 10-Week Web Development

Instructor guides, student handouts, runnable code templates and assessments — everything you need to teach JavaScript from first console.log() to a finished mini-project.

Key philosophy

Read it, run it, change it. Every week ships a runnable code template, so students see the result in the browser immediately.

Target students
Junior High and Senior High. No prior JavaScript needed.
Starting point
Students already know some HTML and CSS. This course adds JavaScript.
End goal
Every student builds and presents a working interactive web page.
Two tracks
Track A has laptops. Track B works on paper with written assessments.

How each lesson works

Every week page is the full classroom package, split into four tabs.

🧑‍🏫

Instructor guide

Objective, key teaching points, a timing breakdown, the live-code demo and common mistakes to watch for.

📄

Student handout

The explanation, analogies and worked examples — printable, and every example can be run.

🧑‍💻

Code template

The starter file, editable and runnable, with a live preview, a console panel and download.

✅

Assessment

Track A peer pair-checks and Track B written quizzes — answers hidden for the teacher.

Two tracks, one course

Track A

With system

Students have laptops. They code along, run the templates in the browser, and are assessed with peer pair-check checklists.

  • ✓ Run and edit every code template
  • ✓ Peer pair-check after each lesson
  • ✓ Build a real mini-project in Weeks 9–10
Track B

No system

No laptops required. Students work through the printed handouts and are assessed with written quizzes and design documents.

  • ✓ Printed student handouts
  • ✓ Written quiz with code-trace questions
  • ✓ Paper design document and rubric
Weeks 9–10 split by year group

Junior High build one guided interactive element. Senior High plan and build one of three mini-projects: a to-do list, a calculator, or a form validator.

Assessment at a glance

Weekly (Track A)

Peer pair-check checklist, every week:

  • Does the code run without errors?
  • Can the author explain the code in their own words?
  • Can a partner point to a specific concept in the code?

Weekly (Track B)

Written quiz, every week:

  • Short-answer questions on the concept
  • Code-trace questions ("what will print?")
  • Write-a-line questions
  • Answer key hidden behind a collapsible

Final (Weeks 9–10)

  • JHS: final recap quiz (6 questions)
  • SHS: project design document + presentation
  • Both: project showcase rubric
