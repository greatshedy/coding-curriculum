🧑‍💻 Code Playground

Write HTML, CSS and JavaScript, press Run, and watch the page appear next to you. Anything you console.log() shows up in the console panel below — open a lesson's template here if you want to experiment with it.

Tip: press Ctrl + Enter to run.

Try these

  • Change a colour and press Run again.
  • Add a console.log() inside a loop.
  • Make the page react to a button click.

The console is your friend

If something isn't working, log a value and look at the console panel. Red lines are errors — read them carefully, they usually tell you the line number.

Download your work

Press Download to save your page as a real .html file you can open in any browser.
