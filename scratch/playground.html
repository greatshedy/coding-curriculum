🧱 Block Playground

A mini Scratch that runs right here. Click a block on the left to add it to your script, change the numbers, then press Run and watch the cat follow your instructions. It's the same idea as real Scratch — a smaller set of blocks to practise with.

What works here

  • Green flag scripts run when you press Run.
  • Key scripts run when you press that key (click the stage first).
  • Use wait inside forever loops so you can see what's happening.
  • if on edge, bounce keeps your sprite on the Stage.
  • Variables show up on the Stage while the script runs.
